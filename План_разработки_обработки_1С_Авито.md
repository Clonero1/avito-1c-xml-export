# План разработки обработки 1С для XML Авито

## Этап 1. Прототип без выгрузки фото

Цель: проверить, что 1С правильно находит товары, цены и остатки.

Сделать:

- форму внешней обработки `.epf`;
- выбор текущего XML;
- выбор папки результата;
- выбор типа цен, по умолчанию `Кинезис`;
- выбор складов, по умолчанию список из ТЗ;
- получение товаров с положительным остатком;
- получение цены по типу цен `Кинезис`;
- формирование отчётов:
  - товары с остатком и ценой;
  - товары без цены;
  - товары без остатка;
  - товары из XML, которых нет в 1С;
  - товары из 1С, которых нет в XML.

Результат этапа:

- понимание, сколько товаров можно выгружать автоматически;
- список проблемных товаров;
- основа для таблицы соответствий `Код 1С -> Id XML`.

## Этап 2. Таблица соответствий

Цель: связать старые объявления Авито с номенклатурой 1С.

Сделать:

- загрузку таблицы соответствий из Excel;
- хранение соответствий внутри обработки или в регистре 1С;
- проверку дублей:
  - один код 1С связан с несколькими Id XML;
  - один Id XML связан с несколькими кодами 1С;
  - один OEM встречается в нескольких объявлениях.

Результат этапа:

- старые объявления можно обновлять без создания дублей на Авито.

## Этап 3. Формирование XML

Цель: получить рабочий XML для Авито.

Сделать:

- читать текущий XML как шаблон;
- сохранять старые поля объявления;
- обновлять `Price`;
- обновлять `Images`, если есть готовые ссылки;
- исключать товары без остатка;
- новые товары добавлять только если заполнены обязательные поля Авито;
- товары с недостающими полями выводить в отчёт.

Результат этапа:

- файл `avito_autoload.xml`;
- отчёты проверки.

## Этап 4. Фото

Цель: автоматически добавлять фото из присоединённых файлов 1С.

Сделать:

- получить присоединённые файлы номенклатуры;
- выбрать изображения `.jpg`, `.jpeg`, `.png`;
- выгрузить фото на сервер или сайт;
- сформировать публичные HTTPS-ссылки;
- добавить ссылки в XML.

Важно: способ выгрузки фото нужно выбрать отдельно:

- FTP;
- SFTP;
- сетевой диск;
- HTTP API сайта;
- ручная выгрузка в папку сайта.

## Этап 5. Автоматизация

Цель: ежедневная выгрузка без ручной сборки файла.

Сделать:

- сохранять XML в папку, откуда Авито сможет его забрать;
- архивировать предыдущие XML;
- запускать обработку по расписанию;
- отправлять отчёт ответственному сотруднику.

## Что нужно решить до старта разработки

1. Где хранить таблицу соответствий `Код 1С -> Id XML`.
2. Куда физически выгружать фотографии.
3. Каким способом 1С сможет передавать фото на сервер.
4. Кто будет контактом по умолчанию в новых объявлениях.
5. Использовать один общий адрес или адрес по складу.
