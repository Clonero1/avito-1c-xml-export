# Дополнение к ТЗ: ключ связи 1С и Авито

## Главное уточнение

Основной ключ товара в 1С: поле `Код` номенклатуры.

Пример:

```text
RS-00177963
```

## Важное ограничение текущего XML

В текущем рабочем XML этого кода нет. Поэтому старые объявления нельзя автоматически связать с 1С только по полю `Код`.

Текущий XML использует идентификаторы вида:

```text
reman8900461
```

А код 1С вида:

```text
RS-00177963
```

в XML сейчас отсутствует.

## Правильная логика обработки

### Для новых объявлений

Для новых объявлений использовать код 1С как внешний идентификатор Авито:

```xml
<Id>RS-00177963</Id>
```

Это позволит 1С в будущем самостоятельно обновлять объявления без дополнительных таблиц соответствия.

### Для старых объявлений

Для уже существующих объявлений нужен переходный механизм:

```text
Код 1С -> Старый Id XML -> AvitoId
```

Пример структуры:

| Код 1С | Id в XML | AvitoId | Наименование |
|---|---|---|---|
| RS-00177963 | reman8900461 | 7778104819 | ... |

Эту таблицу можно хранить:

- в отдельном регистре сведений 1С;
- в дополнительном реквизите номенклатуры;
- во внешней Excel-таблице на первом этапе;
- во внутренней таблице настроек внешней обработки.

## Рекомендуемый первый этап

1. Сделать обработку, которая формирует отчёт сопоставления:
   - товары из 1С с положительным остатком;
   - объявления из текущего XML;
   - возможные совпадения по OEM, артикулу, бренду, названию и цене;
   - спорные строки для ручной проверки.
2. После ручной проверки сохранить таблицу соответствий.
3. Только после этого включать автоматическое обновление старых объявлений.

## Почему нельзя сразу заменить Id старых объявлений на код 1С

Если в существующем объявлении заменить:

```xml
<Id>reman8900461</Id>
```

на:

```xml
<Id>RS-00177963</Id>
```

Авито может воспринять это как новое объявление, а не обновление старого. Поэтому для уже опубликованных объявлений старый `Id` лучше сохранить до тех пор, пока не будет понятен безопасный сценарий перехода.

## Итоговое правило

- Новые объявления: `Id = Код 1С`.
- Старые объявления: использовать таблицу соответствий `Код 1С -> старый Id XML`.
- После накопления соответствий можно постепенно перейти к полной автоматической выгрузке из 1С.
