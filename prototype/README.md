# Python-прототип сопоставления XML Авито и остатков 1С

Этот прототип нужен, чтобы проверить алгоритм сопоставления на реальных XML/XLSX до переноса логики в BSL и внешнюю обработку 1С.

Прототип не является обработкой 1С и не создаёт готовую `.epf`. После проверки правил нормализации, сопоставления и отчётов логика переносится в модуль внешней обработки.

## Входные файлы

Реальные файлы для локального теста нужно положить в `prototype/input/`:

- `prototype/input/avito_autoload.xml` — текущий XML Авито;
- `prototype/input/stock.xlsx` — Excel-файл остатков из 1С.

Рабочие XML/XLSX не нужно коммитить в репозиторий, если они содержат реальные данные.

## Настройка

Пример конфигурации находится в `prototype/sample_config.json`.

В конфиге нужно указать:

- `xml_path` — путь к текущему XML Авито;
- `stock_xlsx_path` — путь к Excel-файлу остатков;
- `output_dir` — папку результата;
- `stock_sheet_name` — имя листа Excel или `null`;
- `stock_header_row` — номер строки заголовков, начиная с 1, или `null` для автоопределения;
- `columns` — названия колонок из Excel;
- `comparison` — настройки нормализации и сравнения;
- `xml.update_price` — обновлять ли `Price` из Excel.

По умолчанию `xml.update_price` оставлен `false`, потому что в упрощённой таблице остатков может не быть цены.

## Установка зависимостей

```bash
python -m pip install -r prototype/requirements.txt
```

## Запуск

```bash
python prototype/compare_avito_xml_with_1c_stock.py --config prototype/sample_config.json
```

## Тесты

Запуск из корня репозитория:

```bash
python -m pytest prototype/tests
```

## Результаты

В папке `output_dir` создаются:

- `avito_autoload_filtered.xml` — XML на базе исходного файла, без объявлений к снятию;
- `compare_report.xlsx` — общий Excel-отчёт.

В `compare_report.xlsx` есть листы:

- `Итог`;
- `Добавить на Авито`;
- `Снять с Авито`;
- `Совпадают`;
- `Ручная проверка`;
- `Дубли XML по OEM`.

## Ограничения

- это не обработка 1С `.epf`;
- новые товары не добавляются в XML автоматически;
- фотографии не выгружаются и не меняются;
- категории Авито не пересчитываются;
- старые `Id` не меняются;
- `Id`, `Title`, `Description`, категории и `Images` сохраняются из исходного XML;
- текущий XML используется как шаблон;
- XML не генерируется с нуля;
- точность результата зависит от качества артикулов/OEM в XML и Excel.
