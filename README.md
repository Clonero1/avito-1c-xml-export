# avito-1c-xml-export

Документы для разработки внешней обработки 1С ERP 2.5, которая формирует XML-файл автозагрузки Авито с учетом остатков, цен и фотографий.

## Состав

- `ТЗ_1С_Авито_XML_выгрузка_полное.md` — полное техническое задание.
- `ТЗ_1С_Авито_XML_выгрузка.md` — краткая версия ТЗ.
- `Дополнение_к_ТЗ_1С_Авито_XML.md` — уточнение по ключу связи 1С и Авито.
- `План_разработки_обработки_1С_Авито.md` — практический план разработки по этапам.

## Ключевая логика

- Конфигурация: 1С ERP 2.5.
- Цена: тип цен `Кинезис`.
- Остатки: выбранные склады из ТЗ.
- Фото: из присоединенных файлов номенклатуры, в XML попадают публичные URL.
- Новые объявления: `Id = Код 1С`.
- Старые объявления: через таблицу соответствий `Код 1С -> старый Id XML`.
