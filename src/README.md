# Исходники обработки 1С

В этой папке будут храниться исходники модулей внешней обработки 1С в текстовом виде.

Планируемые форматы:

- `.bsl` — модули 1С / BSL;
- `.os` — если часть логики будет проверяться через OneScript.

На текущем этапе это заготовки для 1С-разработчика. Готовой `.epf` обработки в репозитории пока нет.

## Файлы

- `МодульОбъекта.bsl` — черновой модуль объекта обработки.
- `МодульФормы.bsl` — черновой модуль формы.
- `Запросы_ERP_2_5.bsl` — черновики запросов к ERP 2.5.
