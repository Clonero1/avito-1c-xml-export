# Что ещё не реализовано в BSL-каркасе

## Статус

BSL-файлы являются техническим каркасом, а не готовой рабочей обработкой.

## Не реализовано полностью

1. Чтение XML
2. Получение остатков ERP
3. Получение цен `Кинезис`
4. Получение `Кат. номер2`
5. Получение присоединённых файлов
6. Получение двоичных данных фото
7. Формирование ZIP
8. Запись итогового XML
9. Запись CSV-отчётов
10. Проверка синтаксиса в Конфигураторе

## Что уже зафиксировано

- XML используется как шаблон.
- Старые `Id` не меняются.
- Новые товары автоматически не добавляются.
- `Юрий` не снимается.
- `спецодежда` исключается.
- Существующие `Images` не перезаписываются.

## Что делать первым

1. Собрать `.epf` в Конфигураторе.
2. Проверить синтаксис.
3. Реализовать чтение XML.
4. Реализовать получение остатков.
5. Запустить режим `ПроверитьДанные`.
6. Сравнить результат с Python-прототипом.
