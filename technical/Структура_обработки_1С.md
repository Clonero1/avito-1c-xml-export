# Структура внешней обработки 1С

## Назначение формы

Форма обработки предназначена для ручного запуска выгрузки Авито, проверки данных и формирования отчётов.

На первом этапе обработка должна работать как внешняя обработка `.epf` без изменения типовой конфигурации ERP.

## Реквизиты формы

| Реквизит | Тип | Назначение |
|---|---|---|
| `ТипЦен` | СправочникСсылка.ВидыЦен | Тип цен для выгрузки, по умолчанию `Кинезис` |
| `Склады` | ТаблицаЗначений | Список складов для отбора остатков |
| `ПутьКТекущемуXML` | Строка | Путь к текущему рабочему XML Авито |
| `ПутьСохраненияXML` | Строка | Путь сохранения нового XML |
| `ПапкаСохраненияОтчётов` | Строка | Папка для отчётов |
| `БазовыйURLФотографий` | Строка | Публичный базовый URL фотографий |
| `ПутьВыгрузкиФотоНаСервер` | Строка | Путь или адрес выгрузки фото |
| `МаксимальноеКоличествоФото` | Число | Максимальное количество фотографий на товар |
| `ВыгружатьБезФото` | Булево | Разрешать выгрузку товаров без фото |
| `ИспользоватьТекущийXMLКакШаблон` | Булево | Использовать текущий XML как шаблон |

## Кнопки формы

- `Сформировать XML`
- `Проверить данные`
- `Выгрузить фото`
- `Сформировать отчёты`
- `Открыть папку результата`

## Табличные части формы

### Склады

Поля:

- `Склад`
- `Использовать`
- `СостояниеАвито`
- `КонтактноеЛицо`
- `Адрес`

Склады по умолчанию:

1. Агрегаты восстановленные Реман (Суставов А.)
2. Склад Исток Основной
3. Склад форсунки восстановленные Исток (Суставов А.)
4. Склад деталей REMAN (Суставов А.)
5. Склад форсунки восстановленные Кимры
6. Склад РВД Исток

### РезультатПроверки

Поля:

- `КодНоменклатуры`
- `Номенклатура`
- `Артикул`
- `OEM`
- `IdXML`
- `AvitoId`
- `Статус`
- `Комментарий`

### Ошибки

Поля:

- `КодНоменклатуры`
- `Номенклатура`
- `Причина`
- `Рекомендация`

## Настройки по умолчанию

| Настройка | Значение |
|---|---|
| Тип цен | `Кинезис` |
| Максимальное количество фото | `10` |
| ВыгружатьБезФото | `Истина` |
