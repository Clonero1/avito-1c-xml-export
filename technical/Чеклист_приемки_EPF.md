# Чеклист приёмки EPF

Чеклист используется после сборки внешней обработки `.epf` в 1С Конфигураторе.

## Базовая проверка

- [ ] Обработка открывается в ERP 2.5.
- [ ] Форма отображается без ошибок.
- [ ] Реквизиты формы заполняются.
- [ ] Список складов заполнен нужными складами.
- [ ] Тип цен установлен в `Кинезис`.
- [ ] Путь к текущему XML выбирается.
- [ ] Папка результата выбирается.

## Проверка данных

- [ ] XML читается.
- [ ] Остатки читаются из фактического регистра ERP.
- [ ] Цены читаются из фактического регистра ERP.
- [ ] Дополнительные реквизиты читаются, если используются.
- [ ] Присоединённые файлы номенклатуры доступны, если включена выгрузка фото.
- [ ] Ошибки чтения попадают в отчёт.

## Бизнес-правила

- [ ] Текущий XML используется как шаблон.
- [ ] Старые `Id` не меняются.
- [ ] `Title` не меняется.
- [ ] `Description` не меняется.
- [ ] Категории Авито не пересобираются.
- [ ] Существующий блок `Images` не перезаписывается.
- [ ] Новые товары автоматически не добавляются в XML.
- [ ] Фильтр `спецодежда` работает.
- [ ] Исключённая `спецодежда` попадает в `report_filtered_out.csv`.
- [ ] Правило `Юрий` работает: объявления менеджера не снимаются автоматически.
- [ ] Товары без цены попадают в ошибки, цена не обновляется молча.

## Фото

- [ ] Если в XML уже есть фото, блок `Images` остаётся без изменений.
- [ ] Если в XML нет фото и в 1С есть фото, добавляются `Image name`.
- [ ] Имена фото соответствуют формату `Код1С_1.jpg`.
- [ ] В ZIP нет вложенной папки.
- [ ] В ZIP попадают только `.jpg`, `.jpeg`, `.png`.
- [ ] Количество фото на товар не превышает `МаксимумФото`.

## Отчёты

- [ ] `report_summary.csv` сформирован.
- [ ] `report_exported.csv` сформирован.
- [ ] `report_removed.csv` сформирован.
- [ ] `report_new_items.csv` сформирован.
- [ ] `report_manual_check.csv` сформирован.
- [ ] `report_duplicates.csv` сформирован.
- [ ] `report_filtered_out.csv` сформирован.
- [ ] `report_photos.csv` сформирован.
- [ ] `report_errors.csv` сформирован.
- [ ] CSV открываются в Excel с нормальной русской кодировкой.

## Сверка с Python-прототипом

- [ ] Количество исходных объявлений совпадает с Python-прототипом.
- [ ] Количество объявлений к снятию совпадает или объяснено отличие.
- [ ] Количество новых товаров совпадает или объяснено отличие.
- [ ] Количество ручной проверки совпадает или объяснено отличие.
- [ ] Количество дублей совпадает или объяснено отличие.
- [ ] Итоговый XML содержит ожидаемое количество объявлений.

## Проверка Авито

- [ ] Итоговый XML валидный.
- [ ] Корневой тег и атрибуты XML сохранились.
- [ ] XML проходит валидатор Авито.
- [ ] При загрузке XML Авито не сообщает об ошибках структуры.
- [ ] Если загружается ZIP с фото, Авито принимает архив.

## Решение о приёмке

- [ ] Обработка готова к тестовой загрузке в кабинет Авито.
- [ ] Найденные расхождения записаны в список доработок.
- [ ] Рабочая загрузка разрешена ответственным пользователем.
