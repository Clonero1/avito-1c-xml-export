# Алгоритм сопоставления 1С и XML

## Цель

Сопоставить номенклатуру 1С с объявлениями из текущего рабочего XML Авито так, чтобы обновлять старые объявления и не создавать дубли.

## Приоритеты сопоставления

1. Искать по `Avito_ID`, если реквизит заполнен в номенклатуре.
2. Потом искать по нормализованному OEM.
3. Потом искать по нормализованному артикулу.
4. Потом искать по дополнительным каталожным номерам.
5. Если найдено несколько совпадений, отправить строку в ручную проверку.
6. Если не найдено, отправить товар в отчёт новых товаров или объявление в отчёт снятых товаров.

## Сопоставление по Avito_ID

Если в 1С заполнен реквизит `Avito_ID`, обработка ищет объявление XML по полю:

```xml
<Id>reman8900461</Id>
```

Если найдено ровно одно объявление, связь считается надёжной.

Если найдено несколько объявлений с одним `Id`, это ошибка XML и строка отправляется в отчёт дублей.

## Сопоставление по OEM

Если `Avito_ID` не заполнен, используется нормализованный OEM.

Пример:

```xml
<OEM>270-5323</OEM>
```

и значение `2705323` в 1С считаются одинаковыми после нормализации.

## Сопоставление по артикулу

Если OEM пустой или не дал совпадения, используется артикул номенклатуры.

Артикулы могут быть записаны с дефисами, пробелами и разделителями. Их нужно нормализовать.

## Дополнительные каталожные номера

Если в 1С есть дополнительные каталожные номера, каждый номер нормализуется отдельно и сравнивается с нормализованными значениями XML.

## Спорный случай с суффиксом RN

Суффикс `RN` может означать восстановленную или особую версию детали. Нельзя автоматически считать значения одинаковыми без согласования.

Пример спорного сопоставления:

```text
3918776RN
3918776
```

Рекомендуемое поведение:

- по умолчанию не считать их одинаковыми;
- отправлять в ручную проверку;
- включать автоматическое отбрасывание `RN` только отдельной настройкой.

## Псевдокод нормализации артикула

```bsl
Функция НормализоватьАртикул(Значение) Экспорт

    Если Значение = Неопределено Тогда
        Возврат "";
    КонецЕсли;

    Результат = ВРег(СокрЛП(Строка(Значение)));

    Результат = СтрЗаменить(Результат, "-", "");
    Результат = СтрЗаменить(Результат, " ", "");
    Результат = СтрЗаменить(Результат, Символы.Таб, "");
    Результат = СтрЗаменить(Результат, "/", "");
    Результат = СтрЗаменить(Результат, "\", "");
    Результат = СтрЗаменить(Результат, ".", "");

    Возврат Результат;

КонецФункции
```

## Псевдокод разбора нескольких артикулов

```bsl
Функция ПолучитьНормализованныеАртикулы(Значение) Экспорт

    Результат = Новый Массив;

    Если ПустаяСтрока(Значение) Тогда
        Возврат Результат;
    КонецЕсли;

    СтрокаАртикулов = СтрЗаменить(Значение, ";", ",");
    СтрокаАртикулов = СтрЗаменить(СтрокаАртикулов, "/", ",");

    Для Каждого Артикул Из СтрРазделить(СтрокаАртикулов, ",") Цикл
        Нормализованный = НормализоватьАртикул(Артикул);
        Если Не ПустаяСтрока(Нормализованный) Тогда
            Результат.Добавить(Нормализованный);
        КонецЕсли;
    КонецЦикла;

    Возврат Результат;

КонецФункции
```

## Результаты сопоставления

| Ситуация | Действие |
|---|---|
| Найдено одно надёжное совпадение | Использовать для обновления XML |
| Найдено несколько совпадений | Отчёт ручной проверки |
| Товар есть в 1С, но нет в XML | Отчёт новых товаров |
| Объявление есть в XML, но товара нет в остатках | Отчёт снятых товаров |
| Нет цены `Кинезис` | Отчёт ошибок |
| Конфликт состояния по складам | Отчёт ручной проверки |
