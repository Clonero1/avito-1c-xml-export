# Формат отчётов обработки

## Общие требования

Отчёты должны формироваться после проверки данных и после формирования XML. Формат первого этапа: Excel или CSV.

Каждый отчёт должен содержать дату формирования и параметры выгрузки: тип цен, склады, путь к XML и режим работы.

## Отчёт выгруженных товаров

Файл:

```text
avito_report_export.xlsx
```

Поля:

- `Avito_ID`
- `IdXML`
- `КодНоменклатуры`
- `Артикул`
- `OEM`
- `Наименование`
- `НазваниеXML`
- `Цена`
- `Остаток`
- `Склад`
- `КоличествоФото`
- `СтатусВыгрузки`
- `Комментарий`

Причины попадания:

- товар найден в XML;
- товар найден в 1С;
- остаток больше нуля;
- цена `Кинезис` заполнена;
- объявление включено в новый XML.

## Отчёт ошибок

Файл:

```text
avito_report_errors.xlsx
```

Поля:

- `КодНоменклатуры`
- `Артикул`
- `OEM`
- `Наименование`
- `IdXML`
- `ПричинаОшибки`
- `Рекомендация`

Причины попадания:

- нет цены;
- нет артикула;
- нет OEM;
- не заполнена категория Авито;
- не заполнен тип запчасти;
- не удалось выгрузить фото;
- не найдено соответствие с XML;
- конфликт состояния товара по складам.

## Отчёт товаров без фото

Файл:

```text
avito_report_no_photo.xlsx
```

Поля:

- `КодНоменклатуры`
- `Артикул`
- `OEM`
- `Наименование`
- `Остаток`
- `Склад`
- `Цена`
- `IdXML`
- `Статус`

Причины попадания:

- у товара нет присоединённых изображений;
- изображения есть, но не удалось выгрузить на сервер;
- публичный URL фото не сформирован.

## Отчёт новых товаров

Файл:

```text
avito_report_new_items.xlsx
```

Поля:

- `КодНоменклатуры`
- `Артикул`
- `OEM`
- `Наименование`
- `Цена`
- `Остаток`
- `Склад`
- `Производитель`
- `КакиеПоляАвитоНужноЗаполнить`
- `Рекомендация`

Причины попадания:

- товар есть в 1С;
- остаток больше нуля;
- цена заполнена;
- соответствующее объявление не найдено в XML.

Новые товары не должны автоматически попадать в XML, если не заполнены обязательные поля Авито.

## Отчёт снятых товаров

Файл:

```text
avito_report_removed_items.xlsx
```

Поля:

- `IdXML`
- `AvitoId`
- `OEM`
- `НазваниеXML`
- `ПричинаСнятия`
- `Комментарий`

Причины попадания:

- нет остатка;
- товар не найден в 1С;
- нет цены;
- товар отключён для выгрузки;
- сопоставление стало спорным.

## Отчёт дублей

Файл:

```text
avito_report_duplicates.xlsx
```

Поля:

- `КлючДубля`
- `ТипКлюча`
- `Количество`
- `СписокIdXML`
- `СписокКодовНоменклатуры`
- `СписокНазваний`
- `Рекомендация`

Причины попадания:

- несколько объявлений с одним OEM;
- несколько объявлений с одним артикулом;
- один `IdXML` связан с несколькими товарами 1С;
- один товар 1С связан с несколькими `IdXML`.
