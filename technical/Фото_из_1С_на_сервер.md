# Фото из 1С на сервер

## Контекст

Фотографии товара хранятся в карточке номенклатуры в присоединённых файлах.

Авито не принимает фотографии как вложения внутри XML. В XML должны попадать только публичные URL:

```xml
<Images>
  <Image url="https://site.ru/avito/images/RS-00180081_1.jpg"/>
</Images>
```

## Алгоритм

1. Найти присоединённые файлы номенклатуры.
2. Отобрать изображения `.jpg`, `.jpeg`, `.png`.
3. Сформировать имя файла по коду 1С.
4. Выгрузить файл на сервер.
5. Сформировать публичный URL.
6. Добавить URL в XML.

## Именование файлов

Формат:

```text
КодНоменклатуры_НомерФото.jpg
```

Примеры:

```text
RS-00180081_1.jpg
RS-00180081_2.jpg
```

## Требования к URL

- ссылка должна начинаться с `https://`;
- ссылка должна открываться без авторизации;
- ссылка должна быть прямой ссылкой на изображение;
- сервер должен отдавать изображение, а не страницу предпросмотра;
- ссылка должна быть стабильной, без временного токена;
- Авито должен иметь возможность скачать изображение извне.

## Способ выгрузки

Способ выгрузки на сервер пока не выбран.

Варианты:

- FTP;
- SFTP;
- HTTP API;
- сетевой диск;
- ручная выгрузка.

Этот вопрос вынесен в [open_questions.md](../open_questions.md).

## Поведение при ошибках

| Ситуация | Действие |
|---|---|
| Фото нет | Записать товар в отчёт товаров без фото |
| Фото есть, но формат не поддержан | Записать предупреждение |
| Не удалось выгрузить фото | Записать ошибку или выгрузить без фото, зависит от настройки |
| URL не сформирован | Не добавлять блок `Images` |

## XML-блок Images

```xml
<Images>
  <Image url="https://site.ru/avito/images/RS-00180081_1.jpg"/>
  <Image url="https://site.ru/avito/images/RS-00180081_2.jpg"/>
</Images>
```
